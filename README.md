# NBA 賽季前對戰預測

選兩支 NBA 球隊，用上一季（2025-26 例行賽）的表現推算對戰比分與勝負。純網頁（HTML / CSS / JavaScript），不需要後端伺服器。

> **資料是凍結快照**：目前只含 2025-26 例行賽（截至 2026-04-12，共 1,230 場），拿來當 2026-27 開季前的預測，準確度有限。新球季開打後會更新資料。

## 預測方法

與 [nba-matchup-predictor](https://github.com/kop030183/nba-matchup-predictor)（即時抓資料版）的 PACE 調整法使用同一組公式：

- **PACE 調整法**：把場均得失分依各隊節奏（PACE）換算成每回合得分，再依兩隊平均節奏換算回該場比分，主隊加 1 分主場優勢。

## 準確度

賽季前和賽季中的命中率不是同一件事，請分開看：

- **賽季前預估（本站目前的模式）**：用上一季整季數據預測下一季每一場，勝負命中率約 **60%**（2023-24 → 2024-25 為 61.5%，2024-25 → 2025-26 為 59.7%）。作為對照，「永遠猜主隊贏」約 55%。
- **賽季中回測**：用本季賽前累積數據逐場預測。三季（2023-24 ~ 2025-26）共 3,224 場逐場回測：PACE 調整法勝負命中率約 66.5%。這是賽季中的數字，**不適用於賽季前預測**。此數字來自舊專案的回測，該回測有一個已知的資料瑕疵（NBA 盃決賽被算進例行賽），數字可能微幅變動。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `index.html` / `style.css` / `app.js` | 網頁本體 |
| `data/teams.js` | 網頁讀取的資料（由 `build_data.py` 產生，請勿手改） |
| `build_data.py` | 把 `raw/` 原始比分整理成 `data/teams.js` |
| `raw/` | 2025-26 原始賽程比分與 PACE |

## 本機開啟

直接雙擊 `index.html` 即可。

## 更新到新球季

1. 把新球季的賽程與 PACE 檔放進 `raw/`
2. 修改 `build_data.py` 最上方的 `SEASON_LABEL`、檔名、`REGULAR_SEASON_END`、`EXCLUDED_GAMES`
3. 執行 `python build_data.py`

## 資料來源
